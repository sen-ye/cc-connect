# 回复卡片自动显示 agent 会话 ID

状态栏开启时，cc-connect 会在现有模型、上下文和路径信息之后自动增加完整的 agent 会话 ID，例如：

```text
gpt-6-astra · xhigh · …
/workspace/project
会话 ID: 01234567-89ab-4cde-8f01-23456789abcd
```

ID 来自当前 `AgentSession.CurrentSessionID()`，可以用来匹配 CC Connect 记录中的 `agent_session_id`，由程序生成，不依赖模型回复。新建、恢复和切换会话后均读取当前运行会话的值。

普通状态栏、带 token 统计的状态栏以及富卡片均支持该字段；飞书沿用状态栏的小字样式。提供英语、简体中文、繁体中文、日语、西班牙语标签。ID 保留完整内容，尚未取得 ID 时不显示占位行。

无需增加配置。`reply_footer=false` 仍关闭整个状态栏；隐藏模型/上下文或路径指示器不会隐藏已取得的会话 ID。富卡片保留原来的显示时机：流式处理中不显示页脚，完成或错误状态再显示。

## 验证

- 状态栏单元测试覆盖完整 ID、五种语言、ID 延迟取得、切换后的最新值和状态栏开关。
- 已有 CUJ-I1 增加“聊天 → 新建 → 聊天 → 切回旧会话 → 聊天”，验证用户看到的卡片 ID 自动更新且不重复。
- 飞书卡片测试验证 ID 完整保留且使用小字状态栏样式。
- 全量测试（`CI=1`、`umask 022`）、所有 CUJ、定向 race 检查和 `go build ./...` 均通过。

运行完整检查前，先按项目构建流程生成 `web/dist`。测试命令见项目开发指南。
